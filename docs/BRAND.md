# Brand assets

The MacTape icon was generated with OpenAI image generation and selected for this project. It is a visual metaphor, not an application screenshot. UI screenshots in this repository are captured from the running app and should never be replaced by generated mockups.

## Icon prompt

> Production macOS app icon, 1024 × 1024. A cassette ribbon becomes a compact automation path with three nodes and a play symbol. Premium dimensional glass and satin materials. Graphite and midnight indigo rounded-square tile, warm ivory cassette body, coral and mint accents. Strong small-size silhouette, restrained depth, crisp edges, centered composition. No text, letters, Apple logo, or watermark. Transparent canvas outside the icon tile.

Asset: `assets/MacTape-AppIcon-1024.png`.

## Social card

The social card uses a hand-authored SVG background with the generated icon. Reproduce the 1280 × 640 PNG on macOS with `Scripts/render-social-preview.sh` (requires ffmpeg). This dependency is a documentation tool only; the app has no third-party runtime packages.
