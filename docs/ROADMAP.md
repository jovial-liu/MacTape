# Roadmap

## 0.1 — A workflow you can trust

- Record clicks and modifier shortcuts with Accessibility selectors.
- Edit, reorder, disable, duplicate, import, and export steps.
- Dry run supported steps against the current desktop without performing actions.
- Replay clicks, shortcuts, app launch, waits, assertions, and explicit text variables.
- Human-readable `.mactape` format, CLI validation, and three starter templates.

## 0.2 — Repair instead of rerecord

- Guided selector repair when an application's UI changes.
- Side-by-side comparison of stored and current Accessibility metadata.
- Breakpoints, step-over, retry, and run-from-selection.
- Finder Quick Action and Shortcuts actions.

## 0.3 — Reusable building blocks

- Nested workflows and typed inputs/outputs.
- Conditions over visible UI state.
- Keychain-backed secret references.
- Community template gallery with signed manifests.

## 0.4 — Automation for teams

- Stable workflow-format specification and migrations.
- Screenshot-free CI runner for supported accessible apps.
- Policy files for allowed apps and step types.
- App Intent and MCP surfaces that preserve the same approval model.

## Not planned

- Cloud accounts or hosted workflow execution.
- Covert monitoring or keylogging.
- CAPTCHA bypass or automation intended to evade platform controls.
- Guessing through low-confidence UI matches.
